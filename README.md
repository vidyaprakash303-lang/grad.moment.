# Grand Moments

A modern, responsive luxury functional-hall website built with HTML, CSS and JavaScript.

## 🌐 Live Demo

https://grad-moment.vercel.app

## ✨ Features

- Responsive design for mobile, tablet and desktop
- Luxury event-venue landing page
- Cinematic hero section
- Gallery
- Event packages
- Booking flow
- Contact section
- WhatsApp quick-contact button
- Admin demo panel
- Browser-based content management
- JSON-based content workflow
- Lightweight static frontend
- Vercel-ready deployment

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- JSON
- LocalStorage
- Vercel
